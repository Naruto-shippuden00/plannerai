## 🎬 Keyingi Qadamlar

### 1. GitHub'ga Push Qilish
```bash
cd plannerai
git push origin main
```

**Eslatma:** Agar authentication xatosi bo'lsa:
- GitHub tokeningizni yangilang
- Yoki GitHub Desktop ishlatib push qiling

### 2. Railway.app'ga Deploy Qilish

#### A. Railway Dashboard orqali
1. [railway.app](https://railway.app) ga kiring
2. "New Project" → "Deploy from GitHub repo"
3. `plannerai` repository'ni tanlang
4. Environment variables qo'shing:
   ```
   BOT_TOKEN=your_bot_token
   GROQ_API_KEY=your_groq_key
   ADMIN_USER_ID=your_telegram_id
   TZ=Asia/Tashkent
   ```
5. Deploy tugmasini bosing!

#### B. Railway CLI orqali
```bash
railway login
railway link
railway up
```

### 3. Bot Sozlamalari

#### Telegram Bot Token
1. [@BotFather](https://t.me/BotFather) ga yozing
2. Mavjud botingizni tanlang yoki yangi yarating
3. Token'ni ko'chiring

#### Groq API Key
1. [groq.com](https://groq.com) ga kiring
2. API Keys → Create API Key
3. Key'ni ko'chiring

#### Admin User ID
1. Botingizni ishga tushiring
2. `/start` buyrug'ini yuboring
3. `/id` buyrug'ini yuboring
4. Ko'rsatilgan ID'ni ko'chiring
